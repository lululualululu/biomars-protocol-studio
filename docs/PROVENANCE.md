# Source provenance

The initial Protocol Generation engine was extracted from the project owner's BioMARS repository, `ustc-mbit-robot-biologist/MAS`, at commit `1d776d43b8c1ab07c2b4d979bc71aa5867e4ee40` (2026-11-10). The source repository was private at extraction. The owner explicitly authorized publication of this independent repository and selected the MIT license.

`source-manifest.json` lists the 90 originally selected source paths. The registry and launcher were restricted to Protocol Generation; private-workflow configuration was removed from the public interface; configuration-value logging was reduced. The Studio API, worker adapter, frontend, tests, deployment files, and product/design documents are new in this repository.

Shared workflow data types and orchestration compatibility handlers remain to preserve existing session behavior. Other workflow agents, tools, entrypoints, and their data are not shipped. The source snapshot contains no original Git history, private environment files, private run logs, or original paper PDFs. The later, explicitly requested 50-draft collection is documented in EXAMPLES.md.

Some inherited runtime identifiers and docstrings use the name InternAgent. They are retained as provenance-bearing identifiers from the owner-supplied source, not claims of a separate new implementation. Dependency licenses are retained by their package distributions; MIT here does not relicense third-party dependencies.

The initial illustrative sample remains an asset for backward compatibility. The main application now uses 50 owner-selected historical model outputs with original queries, source metadata, and retained review notes. Paper PDFs and raw full text are excluded; see EXAMPLES.md. The original SVG mark is retained for historical designs. The active brand mark, category icons and cellular hero artwork were generated with built-in GPT Image; asset paths and prompts are recorded in [IMAGE_ASSETS_V5.md](IMAGE_ASSETS_V5.md) and [BIOMEDICAL_LOCAL.md](BIOMEDICAL_LOCAL.md). The interface is implemented in HTML/CSS/JavaScript. Optional Google Fonts have local system-font fallbacks; no third-party screenshots or logos are included in the product.
