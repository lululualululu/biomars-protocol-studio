# Source provenance

The initial Protocol Generation engine was extracted from the project owner's BioMARS repository, `ustc-mbit-robot-biologist/MAS`, at commit `1d776d43b8c1ab07c2b4d979bc71aa5867e4ee40` (2026-11-10). The source repository was private at extraction. The owner explicitly authorized publication of this independent repository and selected the MIT license.

`source-manifest.json` lists the 90 originally selected source paths. The registry and launcher were restricted to Protocol Generation; private-workflow configuration was removed from the public interface; configuration-value logging was reduced. The Studio API, worker adapter, frontend, tests, deployment files, and product/design documents are new in this repository.

Shared workflow data types and orchestration compatibility handlers remain to preserve existing session behavior. Other workflow agents, tools, entrypoints, and their data are not shipped. The source snapshot contains no original Git history, uncommitted working changes, private environment files, research outputs, or original paper PDFs.

Some inherited runtime identifiers and docstrings use the name InternAgent. They are retained as provenance-bearing identifiers from the owner-supplied source, not claims of a separate new implementation. Dependency licenses are retained by their package distributions; MIT here does not relicense third-party dependencies.

The example draft is original, non-operational demonstration text. It links to public background reading rather than redistributing a paper or laboratory SOP. The BioMars mark is an original SVG; the interface is implemented in HTML/CSS. Optional Google Fonts have local system-font fallbacks; no third-party screenshots or logos are included in the product.
