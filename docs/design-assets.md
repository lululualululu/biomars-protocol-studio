# Directions: generated artwork

The 25-direction showcase lives at `/directions/`. Four original raster artworks were generated with the built-in GPT Image tool on 2026-11-13. Text, logos, geometric motifs, interactive diagrams and all layouts remain native HTML, CSS, SVG or Canvas. These decorative concepts are not scientific illustrations or experimental evidence.

Browser assets are JPEG delivery copies, encoded at quality 87 from the unaltered generated PNGs. The generated originals remain in the local image-generation output directory; the repository contains optimized assets only. Fonts use Google Fonts with system fallbacks.
